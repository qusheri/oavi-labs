# Лабораторная работа №7
## Классификация на основе признаков, анализ профилей

### Вариант 4
Используется алфавит варианта 4 и результаты лабораторных работ №5-6.

### Цель
Реализовать классификацию сегментированных символов по мере близости признаков и оценить качество распознавания.

### Метод
Для каждого символа эталонного алфавита вычисляется вектор нормализованных признаков:

```text
масса, cx_norm, cy_norm, mx_norm, my_norm
```

Для каждого сегмента фразы вычисляется евклидово расстояние до всех эталонов. Мера близости рассчитывается как:

```text
S = 1 / (1 + d)
```

Гипотезы сортируются по убыванию меры близости. Лучшие гипотезы образуют распознанную строку.

### Результаты
Гипотезы для исходного размера шрифта сохранены в `output/hypotheses_size52.txt`.

Гипотезы для измененного размера шрифта сохранены в `output/hypotheses_size56.txt`.

Сравнение результатов и доля верно распознанных символов сохранены в `output/summary.csv`.

### Вывод
Классификация по скалярным признакам дает набор ранжированных гипотез для каждого символа. При изменении размера шрифта качество может снижаться, потому что масса и моменты инерции чувствительны к масштабу, поэтому для практического распознавания желательно дополнительно учитывать профили или шаблонное сравнение.
